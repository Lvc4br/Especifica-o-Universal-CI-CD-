Limites atuais

A prévia web não acessa arquivos locais, não conhece o estado do seu repositório em tempo real, não agenda runners, não recebe secrets e não inicia workflows GitHub. Para inspecionar um plano real, use a extensão VS Code 0.5.0 com o motor PowerShell configurado.

System architecture

Modular por desenho.
Seguro por princípio.

O projeto separa o motor de execução, os contratos compartilhados e as integrações. Cada camada tem responsabilidades e fronteiras explícitas.

01 · CORE

PowerShell Engine

Descoberta, validação, planejamento, executor aprovado, timeout, saída limitada e relatórios locais. Fonte da verdade operacional.

02 · CONTRACTS

Shared Intelligence

UPS, geração de planos, resolução de capabilities, análise de DAG e avaliação declarativa de políticas.

03 · INTERFACES

VS Code & GitHub

Extensão VS Code, dashboard local, GitHub App observador e futura evolução de Check Runs.

O protocolo de autorização está documentado como desenho. Identidade, emissão de tokens e autorização executável ainda não estão implementadas.

Segurança: o executor local não é sandbox. Execução remota e runners distribuídos permanecem desativados enquanto isolamento, identidade, gestão de credenciais e controles para código não confiável não estiverem implementados e validados.
